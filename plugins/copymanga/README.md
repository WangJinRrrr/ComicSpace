# 拷贝漫画插件

从你已经登录的拷贝漫画网站，把收藏和阅读历史导入 ComicSpace。只读：不会向网站写入、取消收藏或上报进度。

仓库里原先没有这个插件。它不是完整的漫画源，不能搜索、浏览或打开章节。

## 怎么同步

1. 在浏览器打开你正在用的拷贝漫画站点并登录。
2. 从该站点的请求里复制 Cookie，填到设置里的「登录 Cookie」。网站地址保持 https，并改成地址栏里的域名。
3. 展开这个源，点击「从网站同步收藏和历史」。

本地已有的收藏和阅读进度会保留。同一章节以时间较新的进度为准；时间相同则保留读得更远的一页。网站上没有、但本地有的记录不会被删除。

## 目前读不到账号数据

2026-11-07 检查了公开页面（没有使用真实账号）：

- `https://www.mangacopy.com/web/person/collect`
- `https://www.mangacopy.com/web/person/browse`
- `https://www.mangacopy.com/web/login/`

这些页面是前端空壳（“请耐心等待加载”），收藏和阅读历史不在 HTML 里，而是由站点自己的脚本向未公开接口请求。插件只请求上述普通网页，使用桌面浏览器的 Accept / User-Agent，带上你填写的 Cookie。它不会：

- 调用未公开的会员接口
- 伪装官方客户端或附带应用签名
- 用账号密码登录，或绕过登录和反爬

因此在页面仍是空壳时，同步会失败并说明原因，本地数据不变。这不是“同步成功、账号里没有收藏”。

如果站点以后把收藏或历史直接渲染在个人中心网页里，同一套解析会导入 `/comic/<id>` 和 `/comic/<id>/chapter/<章节>` 链接。这个解析只用夹具测过，没有用真实登录账号验证。

网页通常不包含阅读时间。没有时间时按页面从上到下当作从新到旧，并且只用很小的时间值，所以不会盖过你在 ComicSpace 里更新的进度。页码会记成该章第 1 页。
