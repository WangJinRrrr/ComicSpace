# JMComic 插件

把 JMComic 的移动端 API 接成 ComicSpace 内容源。

- 实现：搜索、分类浏览、筛选、本子详情、章节列表、章节图片
- 协议：复刻 [JUKOMU/JMComic-Api-Java](https://github.com/JUKOMU/JMComic-Api-Java) 的移动端请求签名与 AES 响应解密，不需要 Java 运行时
- 图片：按 `scramble_id` 与章节号计算切块数，通过 `Page.transform` 交给服务端还原后再缓存/下载

## 要求

需要支持 `Page.transform` 的 ComicSpace 版本（图片代理与离线下载会在落盘前还原条带）。旧版本只会返回乱序图片。

## 配置

在设置页填写（全部可选）：

| 字段 | 说明 |
| --- | --- |
| API 域名 | 留空时自动从域名服务器获取可用域名。自动获取失败时填一个可用的 API 域名。 |
| 图片 CDN 域名 | 留空时优先使用 API `/setting` 返回的 `img_host`，否则使用内置 CDN。 |
| 登录 Cookie | 仅用于访问你已登录账号可见的内容；留空以游客身份请求。 |

如果 `img_host` 返回了不在 `plugin.json` 的 `allowedImageHosts` 里的域名，图片代理会拒绝请求。把该域名加进 `allowedImageHosts`，或在设置里手动指定一个已允许的 CDN 域名。

## 稳定性策略

- **域名健康**：某个 API 域名超时、断连或返回非 JSON 后进入指数冷却（20 秒起，最长 5 分钟），之后的请求优先选近期可用、延迟低的域名；会话域名同样受冷却约束，失败后立即失效而不是等满 10 分钟。
- **图片线路轮换**：没有在设置里固定 `imageDomain`、且 `/setting` 没有给出 `img_host` 时，第一次打开章节使用章节模板声明的 CDN；阅读器在图片失败后重新拉取页面列表时，会切到下一台镜像，而不是返回同一批失效 URL。填了 `imageDomain` 则始终固定该域名。
- **请求重试**：API 请求对网络/超时/解析失败最多尝试 3 次，并在不同域名之间轮换；核心的图片代理另有 3 次指数退避重试。

## 调试

```bash
pnpm plugin:check
```

修改插件代码后，在设置页点“重载插件”。

## 已知限制

- 章节页数不在目录接口里，所以章节列表不显示页数。
- 图片会按 JPEG/PNG/WebP 解码后重新编码；GIF 不还原（JM 的 GIF 本身不切块）。
- API 域名和线路会变动；插件会自动发现并缓存 10 分钟，失败域名会进入冷却并被排到候选列表后面。
- 图片 CDN 轮换以章节为单位：同一章内不会逐张切换镜像，避免缓存键被打散。

## 合规

本插件只访问 JMComic 公开 API，不实现付费墙或 DRM 绕过。请只访问你有权访问的内容，并遵守来源站条款与当地法律。
