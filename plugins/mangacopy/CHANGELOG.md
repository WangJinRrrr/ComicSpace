# 拷贝漫画插件更新日志

## [0.1.0] - 2026-10-28

### 新增
- **代理支持**: 新增 `proxyUrl` 配置项,支持通过 HTTP/HTTPS 代理访问拷贝漫画 API
  - 配置格式: `http://127.0.0.1:7890` 或 `https://proxy.example.com:8080`
  - 适用于需要通过系统代理加速访问的场景
  - 代理配置对所有 API 请求和图片请求生效

### 修复
- **图片显示完整性**: 修复某些章节图片只显示一部分的问题
  - 检测并处理拷贝漫画的条带反转(`band-reverse`)防盗图技术
  - 当 API 返回 `is_long: true` 时,自动应用 10 条带反转转换
  - 服务端会在缓存前还原图片,确保正确显示

### 技术细节
- 使用 `undici` 的 `ProxyAgent` 实现代理功能
- 图片转换通过 `Page.transform` 字段传递给服务端处理
- 代理配置通过插件的 `PluginContext.fetch` 透明应用

### 配置示例

```json
{
  "proxyUrl": "http://127.0.0.1:7890"
}
```

### 升级指南
1. 更新插件代码
2. 重启应用或重载插件
3. 在插件设置中配置代理服务器地址(可选)
4. 如遇图片显示问题,请清除缓存后重新加载
